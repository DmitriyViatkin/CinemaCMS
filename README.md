# CinemaCMS (Kino CMS)

Сайт кінотеатру з власною CMS-системою управління (адмінкою) для керування репертуаром, сеансами та бронюванням квитків.

## 🧩 Функціонал

- Публічна частина сайту — афіша фільмів, розклад сеансів, бронювання квитків
- Адмін-панель — керування фільмами, сеансами, залами кінотеатру
- Верстка сайту та адмінки виконана точно за наданим мокапом

## 🛠 Технологічний стек

- **Backend:** Python, Django (MVT)
- **База даних:** PostgreSQL
- **Frontend сайту:** Bootstrap-компоненти, HTML, CSS, jQuery, JS
- **Frontend адмінки:** AdminLTE, HTML, CSS, Bootstrap, jQuery, JS
- **Інфраструктура:** Docker

## 🗂 Проєктування

- Схема таблиць бази даних (Draw.io)
- Код структурований за архітектурою MVT

## 🚀 Запуск проєкту

```bash
git clone https://github.com/DmitriyViatkin/CinemaCMS.git
cd CinemaCMS

docker-compose up --build
```
